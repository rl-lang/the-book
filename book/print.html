The Rl Book

rl wiki

rl is a statically-typed interpreted language written in Rust with a clean syntax, a TUI REPL, and a growing standard library.

get println from std::display
get factorial, is_prime, fibonacci from std::math

println(factorial(10))   // 3628800
println(fibonacci(15))   // 610
println(is_prime(97))    // true

Installation

From source

git clone https://github.com/rl-lang/rl-lang
cd rl-lang
cargo build --release

Via cargo

cargo install rl-lang

Usage

rl run <file.rl>   # run a source file
rl repl            # start the TUI REPL
rl check <file.rl> # check for errors
rl docs            # print language reference
rl dev             # run project via rl.toml
rl new <name>      # create a new project

1. Comments

single-line comments start with //, everything after is ignored

// this is a comment

3. Constants

declare an immutable value with CONST <type> <name> = <value>, convention is UPPER_CASE

constant arrays use CONST arr[<type>]

rl is statically typed: int, float, bool, string, char

5. Arrays

typed, zero-indexed, mutable — declare with dec arr[<type>] <name> = [<items>]

dec arr[int] nums = [10, 20, 30]
println(nums[0]) // 10
nums[1] = 99
println(nums) // [10, 99, 30]

nested arrays are supported

dec arr[arr[int]] matrix = [[1, 2], [3, 4]]
println(matrix[0][1]) // 2

all elements must share the same type

dec arr[int] nums = [1, 2, 3]
// dec arr[int] bad = [1, "two"] // error: type mismatch

<- Previous: Types · Tutorial · Next: Operators ->

6. Operators

arithmetic (+ - * /), grouping with () controls order

dec int x = (2 + 3) * 4 // 20
dec int y = 2 + 3 * 4   // 14

comparison (== != < <= > >=) always returns bool, logical ! negates

println(5 == 5, 5 != 3, 3 < 10) // true true true
println(!true) // false

method-style call with . passes the value as the first argument

get arr_push from std::array
dec arr[int] nums = [1, 2, 3]
println(nums.arr_push(4)) // [1, 2, 3, 4]

7. Control Flow

if / else if / else branch on conditions

dec int score = 75
if (score >= 90) {
    println("A")
} else if (score >= 75) {
    println("B")
} else {
    println("F")
}

while loops as long as the condition is true

dec int i = 0
while (i < 3) {
    println(i)
    i += 1
}

break exits a loop early, continue skips to the next iteration

dec int i = 0
while (i < 5) {
    i += 1
    if (i == 3) { continue }
    println(i) // 1 2 4 5
}

<- Previous: Operators · Tutorial · Next: For Loops ->

8. For Loops

C-style for loop: explicit init, condition, increment

dec int sum = 0
for [int j = 1, j < 6, j += 1] {
    sum += j
}
println(sum) // 15

range-based for loop: for <var> in <start>..<end> (exclusive)

dec int product = 1
for k in 1..5 {
    product *= k
}
println(product) // 24

iterable for loop walks an array directly

dec arr[int] evens = [2, 4, 6]
dec int even_sum = 0
for n in evens {
    even_sum += n
}
println(even_sum) // 12

13. Entry Points

source files work as scripts when no entry function is present

Types

rl is statically typed every variable has a declared type

dec int    x = 42

dec float  y = 3.14

dec bool   b = true

dec string s = "hello"

dec char   c = 'a'

int is a 64-bit integer

dec int x = 100
dec int neg = -42

float is a 64-bit floating point number

dec float pi = 3.14
dec float neg = -0.5

bool is either true or false

dec bool on = true
dec bool off = false

string is a string enclosed in double quotes

dec string name = "Mohamed"
dec string empty = ""

char is a single character enclosed in single quotes

dec char letter = 'a'
dec char digit  = '9'

Variables

declare a mutable variable with dec <type> <name> = <value>

dec int x = 10
dec float y = 3.14
dec bool flag = true
dec string name = "Mohamed"
dec char c = 'a'

reassign a mutable variable with =

dec int x = 1
x = 2

compound assignment: +=, -=, *=, /=

dec int x = 10
x += 5   // 15
x -= 3   // 12
x *= 2   // 24
x /= 4   // 6

Constants

declare a constant with CONST <type> <name> = <value> but it cannot be reassigned, convention is UPPER_CASE (but anything works)

CONST int    MAX_SIZE  = 100

CONST float  EULER     = 2.71828

CONST bool   DEBUG     = false

CONST string LANG      = "rl"

CONST char   NEWLINE   = '\n'

constant arrays use CONST arr[<type>]

CONST arr[int]    PRIMES = [2, 3, 5, 7, 11]

CONST arr[string] DAYS   = ["sat", "sun", "mon"]

Arrays

declare a mutable array with dec arr[<type>] <name> = [<items>]

dec arr[int]   nums  = [1, 2, 3]

dec arr[string]   words = ["hello", "world"]

dec arr[float] vals  = [1.0, 2.0, 3.0]

dec arr[char]  chars = ['.', 'r', 'l']

dec arr[bool] bools = [true, false, true]

access an element by index with arr[i] zero-based

dec arr[int] nums = [10, 20, 30]
println(nums[0])  // 10
println(nums[2])  // 30

assign to an index with arr[i] = value

dec arr[int] nums = [1, 2, 3]
nums[1] = 99
println(nums)  // [1, 99, 3]

arrays are typed and all elements must be the same type

dec arr[int] nums = [1, 2, 3]
// dec arr[int] bad = [1, "two"]  // error: type mismatch

nested arrays are supported

dec arr[arr[int]] matrix = [[1, 2], [3, 4]]
println(matrix[0][1])  // 2

Functions

declare a function with fn <name>(<type> <param>, ...) { <body> }

greet("Mohamed")

fn add(int a, int b) -> int {

dec int result = add(3, 4)  // 7

functions are first-class values and can be stored in variables

    return x * 2

dec fn f = double
println(f(5))  // 10

Control Flow

if runs a block when the condition is true

dec int x = 10

if (x > 5) {
    println("big")
}

else if and else add additional branches

dec int x = 5

if (x > 10) {
    println("big")
} else if (x == 5) {
    println("five")
} else {
    println("small")
}

while loops as long as the condition is true

dec int i = 0

while (i < 5) {
    println(i)
    i += 1
}

break exits a loop early, continue skips to the next iteration

dec int i = 0
while (true) {
    if (i == 3) { break }
    i += 1
}

dec int i = 0
while (i < 5) {
    i += 1
    if (i == 3) { continue }
    println(i)  // prints 1, 2, 4, 5
}

For Loops

C-style for loop: for [<type> <var> = <init>, <condition>, <increment>] { }

for [int i = 0, i < 5, i += 1] {
    println(i)
}

range-based for loop iterates from start to end (exclusive): for <var> in <start>..<end>

for i in 0..5 {
    println(i)  // 0 1 2 3 4
}

iterate over an inline array literal

for x in [10, 20, 30] {
    println(x)
}

iterate over an array variable with for <var> in <array>

dec arr[string] names = ["ali", "bob", "carl"]

for name in names {
    println(name)
}
